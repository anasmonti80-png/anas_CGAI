## الطريقة المفضلة لاستخدام البرومبت

1. **إذا كانت أداة التطوير تقرأ ملف Markdown طويلًا**: ارفع `MASTER_PROMPT_COMPLETE.md` مباشرة واطلب بدء تحليل وتطوير النطاق المصرح به مع سجل تتبع لجميع IDs.
