# تغطية متطلبات CyberGuard AI

## حالة الجرد

المصدر الرسمي هو `02_REQUIREMENTS/CG_Requirements_1440.jsonl`: النطاق CG-001..CG-1440، 1,440 سجلًا محفوظًا حرفيًا. حالة كل سجل في المصدر هي `historical_unreviewed` ما لم تضف مراجعة لاحقة قابلة للتدقيق. لا يثبت هذا الملف تنفيذ أي متطلب أو قبوله.

## نموذج التتبع المطلوب

| الحقل | المعنى |
|---|---|
| requirement_id | معرف CG الأصلي دون تغيير |
| scope_owner | CyberGuard أو NCC أو IT Twin أو Tickets أو حد تكامل |
| capability | الوحدة الوظيفية المعتمدة |
| implementation | مسار مكوّن أو `not-built` |
| test_id/result | اختبار فعلي ومنصة ونتيجة، أو `not-run` |
| evidence | رابط أثر قابل للمراجعة، أو `none` |
| status | planned / partial / verified / blocked؛ لا تصبح verified بلا دليل |
| restrictions | التفويض والخصوصية والترخيص والقيود التشغيلية |

## قرار التغطية الحالي

لا توجد نتائج تنفيذ أو اختبار معتمدة في هذا الفرع. المطلوب التالي هو إنشاء مصفوفة مولدة من JSONL لا تغيّر النص الأصلي، ثم مراجعة كل معرف حسب قرار V3-02 وربطه بمراحل ومعايير قبول.
