# استراتيجية الاختبار

## مستويات الدليل

- **Unit Tested:** منطق ومخططات وصلاحيات وتراجع في بيئة محلية ببيانات اختبار.
- **Lab Tested:** موصل أو جهاز حقيقي داخل مختبر مصرح، مع نسخة نظام وسيناريو إيجابي/سلبي وأثر محفوظ.
- **Production Validated:** دليل إنتاج مستقل ومصرح، بعد مراجعة نطاق ومخاطر؛ لا يُستنتج من اختبار مختبر.

## بوابات إلزامية

1. تحقق سلامة 1,440 ID والنص المصدر قبل توليد أي تغطية.
2. اختبارات auth/RBAC/CSRF وأسرار وسجل تدقيق ومخطط بيانات.
3. اختبار عدم الخلط: IP أو منفذ مفتوح ليس هوية أو جلسة أو اختراقًا.
4. لكل إجراء: نطاق ومعاينة وموافقة منفصلة وانتهاء وتحقق بعد التنفيذ وتراجع.
5. لكل موصل: least privilege، سلوك عند فقد المصدر، حدود rate/cost، وبيانات اختبار منزوعة الحساسية.
6. اختبارات Windows/macOS/Linux مستقلة؛ لا تعمم نتيجة منصة على أخرى.
