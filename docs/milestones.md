# مراحل تنفيذ CyberGuard AI

| المرحلة | الناتج | بوابة القبول |
|---|---|---|
| M0 | جرد 1,440 متطلبًا وADRs ومخاطر ومصفوفة دعم | IDs سليمة، مالك نطاق وقيود لكل قرار |
| M1 | هوية محلية وRBAC وسجل أدلة وأصول ومصادر | اختبارات عزل ومصادقة واستمرار وعدم كشف أسرار |
| M2 | تطبيع أدلة وقواعد كشف وتنبيهات وحالات | اختبار مصدر مفقود وعدم خلط A/B وport/session |
| M3 | اقتراحات وإجراءات typed بموافقة وتراجع | preview/approval/expiry/postcondition/rollback مثبتة |
| M4 | موصلات Windows/macOS/Linux/هوية/سحابة/شبكة | مختبر مصرح لكل موصل ومنصة ودليل قدرة محدود |
| M5 | AI محلي وسياسة egress وSOAR آمن | grounding واختبار prompt injection وموافقات وأدلة |
| M6 | تعافٍ وDevSecOps وإصدار | restore واختبارات أداء وأمن ومنصات وتراخيص مستقلة |

لا تنتقل مرحلة بالوعود أو بيانات اصطناعية موسومة كإنتاج.
