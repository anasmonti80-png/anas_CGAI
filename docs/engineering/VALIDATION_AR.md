# سجل التحقق الهندسي

## مرحلة API — 2026-11-11

البيئة: Windows x64، Node.js 24.21.0، SQLite 3.53.4. المستوى **Unit Tested**؛ يشمل اختبارات تكامل HTTP حقيقية على loopback ببيانات اصطناعية، وليس حساسات مختبر أو شبكة إنتاج.

الأمر: `node --test tests/*.test.js`. النتيجة: **19 ناجح، 0 فاشل، 0 متجاوز**.

تم التحقق من سلامة 1,440 متطلبًا والمجموعات والأرشيف؛ معاملات وتكرار الاستيراد والتراجع عند الخطأ؛ حفظ DB بعد الإغلاق وإعادة الفتح؛ الصلاحيات وCSRF وOrigin/Host والجلسات؛ تدوير وإبطال رمز المصدر؛ عدم دمج جهازين لهما IP نفسه؛ منع إسناد جلسة من منفذ مكشوف؛ فصل حساب A عن B وrelay؛ عدم اعتبار AV المثبت منعًا مختبرًا؛ كشف فقد الرؤية؛ تجميع الدخول الفاشل؛ إقرار التنبيه المستقل عن إغلاق الحادث؛ الموافقة المنفصلة وTTL وتغير الحالة والـrollback؛ صفحات 5,000 أصل اصطناعي؛ ومنع تعديل سجل التدقيق واكتشاف تغيير مصطنع فيه.

لا يعني نجاح هذه الاختبارات اكتمال أي متطلب تاريخي بكل تفاصيله. لا منصة macOS/Linux مختبرة، ولا منع EDR أو موصل مؤسسي حي أو اختبارات إنتاج. الواجهة والمتصفح وتوزيع البرنامج تحتاج تحققًا مستقلًا في المرحلة التالية.
