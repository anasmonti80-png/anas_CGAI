# التبعيات والتراخيص

اختيار 2026-11-11: لا تبعيات تشغيل npm. Node.js 24 مثبت مسبقًا ولا يُنسخ من NCC إلى الحزمة. نستخدم HTTP/crypto/sqlite/test/fs/os المدمجة. Node يحمل ترخيصًا رئيسيًا من نوع MIT وإشعارات تراخيص مكونات مضمّنة متعددة؛ يلزم إرفاق ملف LICENSE الكامل عند توزيع binary. لا نعطي هذا المستودع ترخيصًا مفتوحًا نيابة عن مالكه؛ `private: true` يمنع نشر npm العرضي ولا يغير ظهور GitHub.

SQLite مضمّنة في Node؛ تحقق إصدارها عبر `select sqlite_version()` ضمن تقرير الاختبار. لا تحمل النسخة مفاتيح أو برامج أو صورًا خاصة بمنتج آخر.

| تكامل مرشح | قرار المرحلة الحالية |
|---|---|
| Sysmon / Windows Event APIs / Defender | واجهات/برامج مزود، يلزم تحقق ترخيص وإذن جمع؛ غير مضمّنة |
| osquery / Wazuh / Fleet / Velociraptor | مؤجل؛ مراجعة إصدار وترخيص وكل تبعية قبل اعتماد أحدها |
| SNMP / NAC / NCC | عقد قراءة وأفعال مصرح بها لاحقًا؛ لا اعتماد حسابات موجودة في NCC تلقائيًا |
| Sigma / OCSF | صيغة قواعد ومخطط خارجيان؛ لا ندّعي التوافق قبل محول واختبارات معيارية |
| LLM / cloud AI | غير موصول؛ لا إرسال بيانات أو مفتاح افتراضي |
| Semgrep / Gitleaks / Syft / Grype / Cosign | اختيار وفحص تراخيص مستقل قبل التثبيت أو التوزيع |
| Restic / Kopia / cloud backup | غير موصول؛ لا ادعاء إمكانية استعادة |

المراجعة الحالية تخص مكونات المرحلة الأولى فقط. لا تثبت تراخيص أو سلامة كل الأسماء الواردة في الأرشيف. SBOM وإصدار موقع بوابتان مستقلتان قبل التوزيع الإنتاجي.
