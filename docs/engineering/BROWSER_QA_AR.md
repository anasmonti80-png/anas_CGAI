# تحقق المتصفح — CyberGuard AI 0.1.0

التاريخ: 2026-11-11 UTC / 2026-11-12 بتوقيت الرياض. البيئة: المتصفح المدمج في Codex على Windows، وخادم loopback مستقل على 4311 بقواعد مؤقتة. أسماء المستخدمين والأصول والأحداث اصطناعية، والعناوين من نطاق التوثيق 192.0.2.0/24. لا بيانات عميل أو شبكة إنتاج.

المستوى: **Unit Tested** مع تحقق يدوي لمسار المتصفح. لا يستعمل هذا التقرير عبارة Lab Tested للدلالة على اختبار أجهزة حقيقية.

| المسار | النتيجة المرصودة |
|---|---|
| التهيئة وتسجيل الدخول | إنشاء مسؤول من رمز إعداد اصطناعي ثم الدخول، دون كلمة مرور افتراضية في التشغيل الحقيقي |
| التنقل والأصل والدليل | عرض أصل واحد وثلاثة أحداث وتنبيهين من fixture موسوم، تفاصيل الأصل والأحداث |
| البحث العلوي | البحث عن SYNTHETIC يعرض التنبيه المطابق في جدول الأحداث الأمنية |
| مرشح الخطورة | اختيار Critical مع عدم وجود نتائج يعرض حالة فارغة، ولا يختلق نتائج |
| التحقيق | إنشاء تحقيق من تنبيه، إضافة ملاحظة وتغيير الحالة وحفظهما في الواجهة السابقة المشتركة |
| المستخدم الثاني | إنشاء مسؤول اصطناعي مستقل وتسجيل الدخول بحسابه |
| الموافقة | مقدم الطلب لا يرى زر موافقة لنفسه؛ المراجع الآخر يعتمد المعاينة |
| التنفيذ والتراجع | ظهرت Approved ثم Local change verified ثم Rolled back بعد تنفيذ المسار كاملًا من المتصفح |
| بطاقات التكاملات | بطاقة الثغرات تعرض أنها غير منفذة ولا تجري فحصًا وهميًا |
| المرجع البصري | مقارنة بالمرجع الأصلي 901×885؛ الشريط الضيق والبطاقات وشبكة الأدوات واللوحة البرتقالية والتسلسل الزمني |
| اللغات | عربية RTL وإنجليزية LTR، مع rail جانبي يساري كما في المرجع |
| العرض المتجاوب | عرض 390 px: scrollWidth لا يتجاوز clientWidth. فُحصت أيضًا أحجام 820 و901 وواجهة الكمبيوتر |

لا ندعي تطابقًا بكسليًا مطلقًا أو اختبار قارئ شاشة كامل. بيانات الرسم الاصطناعية محدودة لذلك تختلف الخطوط والأرقام عن الصورة المرجعية. لم تُختبر كل تراكيب أنظمة التشغيل/المتصفحات/التكبير؛ لا زال اختبار إمكانية الوصول الشامل مطلوبًا. متحكمات الواجهة تشترك في الـAPI الذي اختبر رفض الأدوار وCSRF/Host/Origin.

تُختبر استيرادات ملفات Windows في اختبارات HTTP؛ لم يُستورد سجل Windows حقيقي عبر المتصفح. لم يُشغّل جرد الجهاز المحلي أو مصدر خارجي أثناء هذه الجولة.
