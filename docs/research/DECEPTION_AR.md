# بحث CG-164: الخداع عالي الإشارة (طُعم)

تاريخ المراجعة: 2026-11-27. المصادر رسمية، وروابطها في آخر الوثيقة.

## الأساس: MITRE D3FEND Deceive

يعرّف D3FEND تكتيك Deceive بأنه استخدام الخداع لإغراء المهاجم وإتاحة وصوله إلى بيئة مراقبة أو مضبوطة. ويضم تقنيتين رئيسيتين، لكل منهما فروع:

| التقنية | المعرّف | المعنى |
|---|---|---|
| Decoy Environment (Honeypot) | D3-DE | مضيفات وشبكات مُعدة للخداع، وفروعها: Integrated Honeynet ‏(D3-IHN)، وConnected Honeynet ‏(D3-CHN)، وStandalone Honeynet ‏(D3-SHN) |
| Decoy Object (Lure) | D3-DO | كائن طُعم مُنشأ للخداع |
| Decoy User Credential | D3-DUC | بيانات اعتماد طُعم |
| Decoy File | D3-DF | ملف طُعم |
| Decoy Session Token | D3-DST | رمز مصادقة طُعم |
| Decoy Network Resource | D3-DNR | مورد شبكي طُعم |
| Decoy Persona / Public Release | D3-DP / D3-DPR | هوية أو نشر عام طُعم (خارج نطاق CyberGuard) |

## ما يفعله المزودون

- **Defender for Identity:**
  - يتيح وسم حسابات المستخدمين والأجهزة بـ Honeytoken.
  - هذه الحسابات «خاملة عادة».
  - أي تسجيل دخول من حساب طُعم يرفع تنبيهًا.
- **Windows، الحدث 4663 (محاولة وصول إلى كائن):**
  - لا يُسجَّل إلا إذا احتوت SACL الكائن على ACE مناسب، ضمن فئة Audit File System.
  - يتضمن اسم الحساب واسم الكائن والعملية وصلاحيات الوصول المستخدمة.
  - لذلك يلزم ملف الطُعم تدقيقُ وصول (SACL) حتى يُرى لمسه.

## القرار في CyberGuard

CyberGuard ينفذ D3-DUC وD3-DF وD3-DST وD3-DNR كسجل طُعم معتمد وكشف على الأدلة المخزنة. ولا ينشئ شبكات خداع (Honeynets)، ولا ينشر أي طُعم بنفسه.

1. **موافقة واضحة:**
   - يُقترح الطُعم بمرجع تفويض ومالك وموضع.
   - لا يعمل إلا بعد أن يعتمده مسؤول غير مقترحه، مع MFA حديث.
   - ينتهي خلال 1 إلى 365 يومًا، ويمكن تقاعده.
   - كل خطوة في سجل التدقيق.
2. **دون بيانات اعتماد حقيقية:**
   - لا يقبل CyberGuard كلمة مرور ولا مفتاحًا ولا رمزًا للطُعم، ويرفض أي نص يشبه بيانات اعتماد.
   - رمز الطُعم علامة `CGDECOY-…` يولّدها CyberGuard، وتُعرض مرة واحدة.
   - لا تصادق العلامة في أي نظام، ولا يُخزن منها إلا بصمة SHA-256 وبادئة قصيرة.
3. **عزل آمن يشهد عليه المالك:**

   | نوع الطُعم | ضوابط العزل المطلوبة |
   |---|---|
   | حساب طُعم | بلا صلاحيات، والدخول ممنوع أو معطل، والدخول مراقب |
   | ملف أو مشاركة طُعم | للقراءة فقط، وخارج بيانات الإنتاج، وتدقيق وصول (SACL) |
   | رمز طُعم | لا يصادق في أي مكان |

4. **الكشف:** يُفحص كل حدث مخزن مقابل الطُعم الفعّال:
   - تطابق دقيق لاسم حساب الطُعم في أدلة المصادقة والدخول والوصول عن بُعد، بصيغ `DOMAIN\name` و`name@domain`. الأسماء المشابهة لا تُطابق.
   - ظهور مسار ملف أو مشاركة الطُعم.
   - ظهور علامة رمز الطُعم في أي حدث.
   - أدلة النشر التي تحمل مرجع تفويض الطُعم نفسه لا تُعد لمسًا.
   - النتيجة تنبيه `CG-DECOY-TRIGGER-164` بدرجة «عالية»، ويُعامل مصدر اللمس كمخترق حتى يثبت غير ذلك.

## الحدود

- لا ينشئ CyberGuard الحسابات ولا الملفات ولا يضبط SACL؛ المالك ينشرها.
- يعتمد كشف الملف على وصول أدلة تذكر مساره، مثل 4663 أو سجلات خادم الملفات أو أوامر العمليات.
- لم يُختبر على بيئة حقيقية، بل على أدلة اصطناعية.
